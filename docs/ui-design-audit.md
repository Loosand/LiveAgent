# UI 第一阶段整理记录

当前目标是清理零散样式并保留现有外观，为后续统一设计规范准备基础。
具体变量用法见 [UI 样式变量](ui-style-variables.md)。本文件记录当前实现，
不作为字号、颜色、圆角或间距应当采用哪一档的设计规范。

此前 `feature/ui` 的大范围视觉收敛方案已经回撤。原记录中的固定视觉尺度、
组件样板 `/design.html`、设计审计命令和完成计数不适用于当前代码，已移除。
暂不恢复根目录的设计规范文档。

## 当前整理范围

- GUI、Gateway WebUI 和共享 UI 使用 Tailwind v4 的 CSS `@theme`。
- 原有字号、尺寸、颜色、阴影、断点和动效保留数值；固定样式接入共享变量。
- 标准 Tailwind 类继续使用；特殊尺寸使用 `text-14px`、`h-18px` 等具名类。
- 时间变量统一采用毫秒命名；数值相同的颜色原语合并，阴影和渐变引用这些原语。
- JS 中的斜纹背景改为具名背景类；SSH 面板、楼层导航、快捷键高亮和 Git 图颜色接入变量。
- xterm 通过 `lib/terminal/theme.ts` 读取实际颜色和尺寸；Web Animations 读取实际 easing。
  这两种 API 需要解析后的值，不能直接传入 `var(...)`。
- 继续迁移简单的单处 CSS，同时保留共享规则和第三方节点适配。

## 无消费者样式的确认方式

本轮删除前进行了三层核对：

1. 在仓库中搜索完整类名，区分生产代码、测试、文档和 CSS 定义。
2. 扫描 TS/TSX 字符串与模板片段，检查动态拼接、DOM 查询及直接写入类名的路径。
3. 核对实际渲染组件、第三方依赖及样式入口；关键帧单独检查动画名引用，
   组合选择器只移除失效分支，保留仍在使用的分支。

确认删除了 58 个无消费者类名、118 个选择器分支和 10 个无引用关键帧。
主要涉及以下已失效的实现：

| 旧样式 | 当前消费者核对 |
| --- | --- |
| `checkpoint-status-pulse`、`checkpoint-shimmer` | 检查点卡片使用当前共享组件和展开动效；同前缀动态字符串是消息 ID，不是类名。 |
| `hub-chip-enter`、`hub-status-dot` 等 | Hub 页面没有对应类名或动态生成路径；仍使用的 Hub 入场动画保留。 |
| `skills-drawer-*` | 预览使用当前 Drawer/Dialog 实现，不再生成旧浮层类名。 |
| `composer-dropdown*`、`composer-reasoning-trigger` | 当前输入控件使用各自的 Base UI 弹层和状态属性。 |
| 旧 user/assistant/tool/thinking 气泡类、工具展示、页脚和退出按钮 | 核对当前 transcript 分支及用户菜单，旧节点已不存在。 |
| 旧设置工具列表、工具详情浮层及零散行样式 | 核对当前设置页面；没有生成旧类名的入口。 |
| `scroll-area-scrollbar`、`scroll-area-thumb` | 当前共享 ScrollArea 使用工具类及 `data-scroll-area-scrollbar`；属性选择器保留。 |

以下静态搜索无命中的样式有实际消费者，明确保留：

- `settings-content-*`、`settings-section-shell-*`：由设置页 ID 拼接。
- `status-board-tone-*`、`status-board-fact--*`：由状态数据拼接。
- `rct-*`：由 `react-complex-tree` 渲染。
- `xterm-*`、终端滚动条节点：由 xterm 渲染。
- Markdown 任务列表、KaTeX 和 Diff 相关类名：由对应渲染器生成。

## 单处样式与验证边界

此前已迁移 166 个单处类，本轮再迁移 18 个，涉及移动端设置行、滚动容器、
SSH 标签页、通知退出动效等。移动端共享 CSS 的优先级通过前后计算样式对比确认。

几何计算、虚拟列表测量、与运行时回调共用的时序常量、媒体查询条件和品牌 SVG
属于各自的运行契约，未通过近似换算或机械替换改动。

验证结果：

- `pnpm --filter @liveagent/ui typecheck`、`pnpm check:ui-boundaries` 通过。
- `pnpm --filter liveagent build`、`pnpm --filter @liveagent/gateway-webui build` 通过。
- `pnpm test:gui`：3,045 项通过；`pnpm test:webui`：714 项通过。
- 浏览器 24 组常规对比及 12 组减少动态效果对比，共 5,310 组元素场景；
  包含父子元素的计算样式，无差异。覆盖两端、亮暗主题、关键宽度和字号缩放。
- 两端亮暗主题的 xterm 初始化通过，每套 26 个颜色值与原调色板一致；
  Web Animations 接受解析后的曲线值。实际通知组件的自动关闭回调与退出类切换通过。
- 残留扫描未发现已删除类名的生产引用、缺失样式变量或重复时长值。
- 本轮 CSS 净减少 580 行；源码 Biome 检查通过，互斥媒体条件的优先级提示已注明原因。
  通知关闭的最终修正另跑相关测试及浏览器组件验证通过。

浏览器检查使用组件和样式夹具，不代表已经遍历全部原生终端连接、编辑器、
拖拽及真实业务流程。源码改动可通过本轮差异恢复，没有修改存储格式或运行配置。


## 按钮与输入框的代码收敛

本次继续保持原有样式，只整理重复代码。盘点共享 UI、GUI 和 Gateway WebUI 的
840 处直接 JSX 声明：310 处 Button、356 处原生 button、117 处 Input、26 处原生
input、23 处 Textarea、3 处原生 textarea、5 处 NumberInput。这是源码声明计数，
不代表运行时实例数，也不包含其他自定义组件内部生成的控件。

| 已整理项 | 消费者与改动 | 保留的契约 |
| --- | --- | --- |
| 图标按钮尺寸 | 23 处 `h-7 w-7` 改用 `size="icon-xs"`，24 处 `h-8 w-8` 改用 `size="icon-sm"`；另外 5 处移除与原 `icon` 相同的 `h-9 w-9` 覆盖。 | 两个新尺寸直接复用原 Tailwind 类；颜色、圆角、内边距、焦点、禁用态及事件处理均保留。 |
| 文本输入基础样式 | Input 和 Textarea 的 16 个相同工具类由 `components/ui/text-field-styles.ts` 维护。 | 单行高度、各自纵向内边距、textarea 最小高度、文件输入样式和 Input 的过渡效果仍由原组件维护；调用方覆盖顺序不变。 |
| 侧栏重复样式 | `ChatHistorySidebar` 与 `ChatHistorySidebarRows` 的项目图标按钮、重命名输入框样式由 `ChatHistorySidebarStyles.ts` 共同维护。 | 共享字符串逐字保留；菜单打开态、透明背景、缩放字号和键盘处理不变。 |

这些调整消除了重复维护的样式组合，没有新增包装组件、依赖或全局 CSS，也未改动
默认 Button 尺寸及普通文本按钮。现有样式变量仍是具体数值的维护入口。

以下候选经核对继续保留，避免改变现有行为：

- 原生图标按钮和 Button 的 hover、焦点、禁用透明度并不一致。例如图片预览的
  禁用透明度为 35%，基础 Button 为 50%；整类替换会改变外观。
- Remote/CUA 的局部复制按钮与通用 CopyButton 在尺寸、提示和复制反馈时序上
  有差异，本次未合并复制逻辑。
- NumberInput 的 Base UI 组容器、增减按钮及无效状态不等同于文本输入控件。
- 原生 input 中包含文件、单选、内嵌搜索等用途；未机械替换成带边框的 Input。
- `ProjectToolsPanelToggle` 在调用方 className 之后强制指定尺寸；直接把尺寸移至
  Button 默认变体会改变覆盖优先级，因此保留原写法。
- 侧栏图标样式还供 DropdownMenuTrigger 直接使用；尺寸继续留在这份共享样式中。

本次验证：

- 改动前后共享 UI 类型检查均通过；UI 边界检查和改动源码 Biome 检查通过。
- GUI、Gateway WebUI 生产构建通过；前端测试分别为 3,045 项、714 项，全部通过。
- 2,205 组修改前后真实 React 渲染比较无差异，包含六种按钮外观和调用方覆盖；
  比较时仅忽略 class 属性内部的类名顺序，保留类名集合、标签及其他 DOM 属性。
- 浏览器覆盖两端、亮暗主题、1600/380 像素宽度，共 8 组；每组 957 个控件场景的
  普通和禁用状态计算样式一致，另检查 Button、Input、Textarea 的实际焦点状态。
- 实际组件的默认按钮类型、链接组合、ref、输入事件及调用方样式覆盖验证通过。
  三处依赖旧尺寸写法的源码断言改为检查新尺寸属性及原交互样式。

验证使用实际基础组件与两端样式入口，不代表逐页遍历了全部业务流程；hover 等
伪类的工具类集合保持一致，但本轮未逐个进行鼠标悬停截图对比。恢复时仅反向应用
本次组件、消费者、测试和本节文档的差异，保留此前已经暂存的变量与 CSS 整理。
